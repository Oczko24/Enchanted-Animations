# Contributing to Enchanted Animations

Thank you for your interest in contributing to Enchanted Animations! We want to make contributing to this project as easy and transparent as possible.

## How to Contribute

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.
2. **Clone the Repo**: Clone your fork to your local machine.
3. **Install Dependencies**: Run `npm install` to install all necessary packages.
4. **Make Changes**: Create a new branch for your feature or bugfix (`git checkout -b feature/my-feature`).
5. **Follow the Style Guide**: We strictly follow Material You design principles. Ensure your code is clean and animations are smooth.
    - **No `!important` in CSS**: Use higher specificity instead.
    - **Test your CSS**: Make sure it passes `npm run lint:css` without warnings.
6. **Commit**: Make sure your commit messages are clear and descriptive.
7. **Push and Pull Request**: Push your branch to GitHub and open a pull request against our `main` branch.

## Development Setup

```bash
npm install
npm run dev
```

## Bug Reports and Feature Requests

If you find a bug or have a great idea for a new feature, please open an issue in the GitHub repository. Provide as much detail as possible, including Obsidian version, OS, and screenshots or videos if applicable.

Thank you for helping make Obsidian a more beautiful experience!
