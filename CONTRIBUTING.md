# Contributing to Enchanted-animations

Thank you for wanting to improve this plugin!

## How to contribute:
1. **Bugs & Features**: Open an issue on GitHub.
2. **Pull Requests**:
   - Fork the repo and create your branch.
   - Make changes in `src/` (TypeScript) or `styles.css`.
   - Build using `npm run build` and test.
   - Open a Pull Request.
