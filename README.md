## Features

- Customisable animation speed and their look in whole obsidian
- Turn on/off specific UI elements animations
- Control over every animation you can find in obsidian

### Main objective 

Is to animate everything possile, i offer often updates with new UI animations:))

## How to Install

1. Open Settings → Community Plugins
2. Turn off Safe mode
3. Click Browse
4. Search for "Enchanted Animations"
5. Click Install
6. After installation, enable the plugin and configure it!

## Usage

After enabling the plugin, you can configure:
- Animation speed
- Animation ease
- Whether to animate specific UI elements
- And much more!
